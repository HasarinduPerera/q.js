C.js - Classical Circuit Simulator

C.js is a classical (digital) circuit simulator inspired by the quantum circuit simulator Q.js. Build and test logic circuits using classical logic gates like AND, OR, NOT, NAND, NOR, XOR, and more!

Creating Circuits Programmatically

Creating a Circuit

// Create a circuit with 3 bits and 5 time steps
const circuit = new C.Circuit(3, 5)

// Set input bit values
circuit.bits[0] = C.Bit.ONE
circuit.bits[1] = C.Bit.ZERO
circuit.bits[2] = C.Bit.ONE

// Add gates
circuit.set$('NOT', 1, 1)   // NOT gate on bit 1 at moment 1
circuit.set$('AND', 2, 1)   // AND gate on bit 1 at moment 2

// Evaluate the circuit
circuit.evaluate$()

// Get results
console.log(circuit.report$())

Using Text-Based Circuit Creation

// Create a circuit from text
const circuit = C`
	NOT-AND-I
	I---OR--I
	I---I---XOR
`

// Create a DOM editor for it
const editor = circuit.toDom()
document.body.appendChild(editor)

API Reference

C.Bit - Represents a classical bit (0 or 1)

C.Gate - Represents a logic gate operation

C.Circuit - Represents a complete circuit with bits and gates

C.Circuit.Editor - Interactive DOM-based circuit editor
